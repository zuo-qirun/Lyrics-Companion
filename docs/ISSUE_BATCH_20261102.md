## 有实现但仍需现场确认的播放器问题

- **#158 / #173（QQ / 酷我）**：通知携带标准媒体 token，且包名、标题对应时，尝试读取真实媒体时间轴；无可用状态时，仅在通知进度最大值能与歌曲时长的毫秒 / 秒刻度对应时换算粗进度。不将任意百分比或通知发布时间当作播放时钟。缺少 token、歌曲时长或可解释的进度时继续明确提示无进度。未宣称已经适配反馈中的封闭车机版本。

- **#125 DC Player、#113 原车酷狗、#100 零听**：缺少可用元数据、通知或已验证厂商接口；不按产品名称猜接口。既有调查继续保留在播放器兼容说明中。

## 技术来源与许可

太阳高度计算参考 [NOAA 公开太阳位置公式](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)。
通知进度的最大值由发送者定义，见 [Android Notification 文档](https://developer.android.com/reference/android/app/Notification#EXTRA_PROGRESS_MAX)；媒体时长的单位为毫秒，见 [MediaMetadata 文档](https://developer.android.com/reference/android/media/MediaMetadata#METADATA_KEY_DURATION)。
写真查询使用 [Wikidata 数据接口](https://www.wikidata.org/wiki/Wikidata:Data_access)及 [Commons imageinfo](https://www.mediawiki.org/wiki/API:Imageinfo)，作者和许可从每张图片的元数据与原图页取得，参见 [Commons 复用说明](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia)。图片许可独立于项目代码许可，不打包或二次分发图片。
现有 Folia 改编代码及 AGPL-3.0-only 归属仍见 `third_party/folia/NOTICE.md`，本批次不替换上游声明。
