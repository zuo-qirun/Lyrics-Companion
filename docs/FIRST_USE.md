# 首次使用

新安装首次从桌面图标打开时，在当前设置页上显示八步悬浮引导：页面导航、设置模式、音乐读取权限、悬浮窗权限、主屏歌词开关、显示与外观、实时预览、音乐诊断。
背景变暗，当前真实控件保持高亮，带箭头的说明卡放在控件旁；需要时自动切换分类并滚动到目标。支持上一步、下一步与右上角跳过。
升级用户不会自动重走向导，可在「总览 / 常用 → 设置模式 → 首次使用向导」重新打开。

只浏览、跳过或完成引导不会自动修改输出、样式、设置模式或性能档位；点击高亮控件或说明卡的操作按钮则按普通设置立即生效。
旋转屏幕、主动切换精简 / 完整模式，以及从系统授权页或主屏参数页返回时保留当前步骤。跳过或完成后回到开始引导的分类与滚动位置，且不再自动弹出。
已在系统中授予的权限不随跳过撤销。导出或导入外观配置不会带走首次使用完成状态。

## 权限

- **音乐读取权限**：对应系统的通知使用权，用于读取播放器向系统提供的媒体会话与播放通知。未授权、未连接、没有歌名和没有进度是不同情况。
- **悬浮窗权限**：用于在其它应用上方绘制歌词。部分旧车机在应用信息中管理此权限。
- **可选权限**：录音频谱、使用情况访问、本地目录等在启用对应功能时再申请。向导不会自动开启诊断上传、自启动、图标启动悬浮窗等开关。

### 华为 / 鸿蒙侧载后的敏感权限限制（#161）

若系统明确提示「未知来源应用，系统已拒绝此应用获取敏感权限」，先按照系统「了解如何获取权限」页面的指引操作。
反馈中的入口为「应用信息 → 权限管理 → 右上角 ⋮ → 允许应用获取权限」，其它系统可能显示为「允许受限制的设置」等名称。
解除该限制后，再返回伴侣开启通知使用权和悬浮窗权限；具体路径以设备系统说明为准。
不需要以 root 作为授权步骤。入口不存在或由设备管理策略禁用时，需要向设备厂商确认。

## 精简与完整模式（#133）

精简模式在日常控制与显示页保留主屏常用入口；副屏、追加屏、顶部条等入口在完整模式中管理。
切换模式只收起设置入口，原有参数和已启用的显示输出会保留。设置模式卡始终提供完整模式出口。

## 先判断问题在哪一层

1. 播放器正在播放，伴侣提示等待播放：检查通知使用权、监听器连接与诊断中的会话数量。
2. 有会话但没有歌名：播放器可能没有向第三方发布元数据。换词库无法补出当前歌名。
3. 有歌名但没有进度：只有实际可用的播放器时间轴才能同步滚动；本地歌词文件也不能替代播放时钟。
4. 有歌名与进度但没有歌词：可修正歌名、歌手和乐库，或授权本地歌词目录。
5. 副屏不显示：先确认系统是否枚举到了可绘制的物理屏幕，再检查所选屏幕和显示规则。

请在停车时完成授权和布局调整。模拟器通过不等于车型 ROM、真实播放器和物理多屏验收通过。
