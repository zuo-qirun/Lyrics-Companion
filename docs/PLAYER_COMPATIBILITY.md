# 播放器兼容与反馈前自查

歌词伴侣通过系统媒体接口或播放器通知识别歌曲，再匹配歌词。悬浮窗可以叠加在原车桌面上，但无法嵌入其它应用的状态栏或小组件布局。

## CarPlay / 手机互联客户端

部分客户端只发布空 MediaSession，没有向系统提供歌名、歌手或时长，即使客户端自己的界面显示了歌曲，第三方应用仍无法匹配歌词。红旗 t1c_acrn 上的 `com.aufn.carplay` 已出现这类诊断；不能据此推断所有 CarPlay 客户端都不兼容。

在「歌词 → 音乐状态与诊断」查看结论，上传诊断快照可查看 `sessionCount` 与标题：

- 无媒体会话：检查通知读取权限、播放器是否向系统发布元数据。
- 会话存在但没有可用歌名：重新授权通常不能解决元数据缺失；可尝试手机蓝牙播放并开启「蓝牙 AVRCP 歌曲识别」，或改用车机自带播放器。蓝牙识别仍要求手机与车机传递 AVRCP 元数据。
- 有歌名但没有进度：可以匹配和显示歌曲，但滚动能力取决于播放器提供的播放证据与实时歌词。

不能仅凭另一款仪表歌词应用能显示就判断媒体接口有数据，它可能使用了不同的车机通道。

## 零跑零听及其它待适配播放器

请提供播放器包名、车型、Android 版本、歌词伴侣版本、播放来源（本地文件 / 在线 / 蓝牙 / 手机互联），以及播放中和卡住时的应用内诊断快照。零听暂未取得足够诊断，尚不宣称已适配；不按应用名称猜包名或私有接口。

## 反馈前先检查版本

到「高级 → 应用更新」选择所用通道并检查更新，正式版用户升级到最新正式版，愿意尝鲜的用户选择测试版。旧版遇到的问题可能已经修复。更新卡片显示最近一次检查得到的最新版；诊断与反馈附带通道、最新已知版本、是否落后及实际包名。

没有成功检查更新时，版本状态为未知；断网后显示的是缓存结果，后台标记不代表服务端重新验证过 APK。版本号不是递增次数，版本差距只统计更新历史中已知的版本，日期差由版本名中的发布日期计算。包名一致只表示未发现包名改动，不构成签名或来源验证。

## 灵动岛封面控制

灵动岛样式下，「显示参数 → 背景与封面 → 显示封面」默认开启，按屏幕和样式独立保存。关闭后不画封面或占位圆，文字从胶囊左侧内边距开始排布，回收整个封面及间距的宽度，歌词和第二行共用扩大后的区域与原有居中 / 靠左对齐。

开启显示封面时，「播放器不给封面时 → 隐藏封面区域（版面内收）」在无图或图已回收时同样让出版面；选择显示占位则保持原有圆形占位。行数仍受高度与宽度约束，切歌、无封面及主屏 / 副屏的实际布局仍需车机验证。

## 顶部条与文字特效

顶部条宽度支持 10–100%，取消 160dp 硬下限；可设置左右留白、靠左 / 居中 / 靠右、贴顶、系统状态栏同高与单行 / 双行 / 自动行数。系统状态栏同高强制单行且不画律动条，实际高度以 ROM 上报值为准，不能自动识别原车时钟和天气的位置，请用留白手动避让。

「显示参数 → 歌词特效」提供下列 15 项，默认无特效，按屏幕与样式独立保存。强度为 0 时停用所选效果；只显示当前选项适用的参数。

| 选项 | 实现行为 |
| --- | --- |
| 卡拉 OK 逐字点亮 | 使用真实逐字时间轴；没有逐字数据时按本句时长估算，辉光强度可调。播放速度由播放器决定，不改歌词同步。 |
| 霓虹辉光呼吸 | 文字辉光随周期变化。 |
| 镜像倒影 | 原行下沿的压缩倒影，透明度渐隐，保持原有行高。 |
| 弹性弹跳 | 换句时上下回弹并逐渐收敛。 |
| 仙气漂浮 | 整句轻微上下悬浮。 |
| 流光扫线 | 保留原文字配色，移动窄幅高光。 |
| 律动文字波纹 | 文字按所在横向位置上下形成波浪，属于视觉周期，不读取音频节拍。 |
| 磨砂悬浮底衬 | 半透明底衬与亮边，并非跨窗口高斯模糊。 |
| 彩虹流光 | 彩虹色与原色按强度混合并流动。 |
| 故障抖动 | 间歇的横向扫描条与双色错位残影，保持正文可读。 |
| 星光闪烁 | 保留整句字形，在文字附近添加闪烁星点。 |
| 火焰燃烧 | 暖色渐变随周期变化，带上升火星。 |
| 星辰悬空（模拟 3D） | 文字小幅浮动、缩放与偏移阴影，叠加星点；属于二维纵深模拟。 |
| 流光渐变歌词 | 多色渐变循环流动，与窄幅扫线不同。 |
| 柔滚上移 | 新句从稍低处渐入。 |

动态选项提供速度和 24 / 30 / 60fps，卡拉 OK 的进度始终跟随播放时钟；其速度项隐藏。关闭动画档停用动态选项，镜像与磨砂等静态项仍可使用且不要求额外帧。低帧率会同时限制该面板的逐字与背景重绘；暂停时周期与换句动画跟随播放时钟冻结。选择无特效不影响原有逐字高亮、粒子消散和文字辉光开关。

顶部条在「通知栏歌词详细设置 → 文字特效」提供完整 15 项及无特效，强度、速度和帧率独立保存，不跟随主屏或副屏样式。默认无特效；动态项默认 30fps，可选 24 / 30 / 60fps 或关闭动画。无时间戳的实时歌词按文本换句触发弹跳 / 柔滚，动画仍跟随播放位置；没有播放位置时不推进。系统状态栏同高的窄条保留原裁剪，火焰等外延装饰可能被裁掉，可调整字号或改用较高布局。

直接绘制的歌词共用现有逐字、换行和跑马灯裁剪；离屏缓存的远景模糊歌词保持原渲染，阿拉伯语、印度文字等需要上下文塑形的文字作为整体变形。字形布局和着色器采用有界缓存，较长文本整体变形以控制绘制成本。车机实际帧率、字体与视觉效果仍需实测。
