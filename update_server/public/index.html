03 / GET STARTED

三步，让歌词在眼前。

先让应用认识正在播放的音乐，再选择你喜欢的显示方式。

01

下载并安装

选择适合自己的发布渠道，下载 APK 到 Android 手机或车机，并完成安装。

02

按应用提示授权

开启通知读取与悬浮窗等所需权限。应用会提示各项权限的用途与状态。

03

播放音乐，调整样式

打开播放器播放一首歌，在伴侣里开启歌词显示，再为主屏或副屏调整位置与字号。

正式版和测试版有什么区别？

正式版面向日常使用；测试版会提前提供新功能，也可能存在未验证的问题。两条渠道独立展示与检查更新。测试通道可能提供比旧测试构建更新的正式版，这时下载卡会明确标注。

所有播放器都能显示逐字歌词吗？

逐字效果需要可用的逐字时间轴。实际识别、封面、播放进度和控制能力取决于播放器与系统提供的信息；不具备逐字数据时显示普通歌词或实时歌词。

车机或副屏没显示，怎么办？

先检查权限与目标显示器选择，再查看应用的「音乐状态与诊断」。不同车机 ROM、播放器和外接屏需要实际验证，可通过应用内反馈提供诊断信息。

测试版可以直接切回正式版吗？

关闭测试版通道会恢复正式版检查，但不会自动降级。测试版版本号较高时，需要等待新版正式版；手动安装旧版前应确认签名与设备是否允许降级，保留原应用数据。
