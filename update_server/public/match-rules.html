HOW IT WORKS

规则如何使用？

01 / OPEN

在应用内打开规则市场

进入「设置 → 音乐状态与诊断 → 规则市场」，或从「匹配规则」编辑器的顶部入口进入。

02 / ENABLE

一键下载并启用

下载后即可启用；规则只对匹配的播放器生效。也可以随时停用或移除，不影响内置规则与手动修正记忆。

03 / FALLBACK

原始数据永远优先

规则只追加清洗后的候选查询；原始标题与歌手仍会首先尝试。正则规则受长度与危险模式限制。

想贡献一条规则？
把播放器、异常元数据和期望结果整理成规则包，提交后由维护者审核。

在网页上提交规则 ↓ 规则文档 Wiki ↗ 模板仓库 ↗ 提交规则 ↗

规则由社区提交，经审核后分发；审核通过不代表适配所有播放器版本。规则仅在客户端本地执行，规则包存放在服务器，不写入安装包。 管理员可前往 规则审核台。

SUBMIT A RULE

在网页上提交规则

把规则包 JSON 粘贴或上传到这里即可提交。提交后管理员会审核，通过后出现在上面的规则市场； 提交时会返回一个提交编号和查询令牌，请自己保存，用它们查看审核结果。 也仍然可以从 Wiki / 模板仓库 / GitHub Issue 提交。

同一 IP 每小时最多提交 5 次；提交内容会公开，请勿包含隐私信息。
